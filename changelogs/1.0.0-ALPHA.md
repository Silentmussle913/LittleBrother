# v1.0.0-ALPHA

**Released: 14 March 2026**

For PocketMine-MP API **5.41.x** (Minecraft: Bedrock Edition)

Initial alpha release of **LittleBrother**, introducing the foundational architecture for a packet translation layer that enables **multi-version compatibility** for Minecraft Bedrock Edition servers.

> [!WARNING]
> This is an **experimental release** intended for development and testing.  
> Many packets are still incomplete and breaking changes may occur in future versions.

---

## Added

- Initial project structure
- Packet translation architecture
- Schema-based packet translation system
- Manual packet handler framework
- Protocol data generator (`generate-protocol-data.php`)
- Schema generator (`generate-schema.php`)
