# v1.1.0-ALPHA

**Released: 21 March 2026**

For PocketMine-MP API **5.41.x** (Minecraft: Bedrock Edition)

Major protocol expansion introducing support for **v860** (1.21.120) and **v944** (1.26.10), alongside a significant redesign of the packet translation pipeline with schema-driven architecture and batch-level processing.

> [!WARNING]
> This is an alpha pre-release.
> The translation system has undergone major internal changes and may break existing behavior or integrations.
> Expect instability, desync issues, or incomplete packet handling. Not recommended for production use.

---

## Added

### Protocol Support

* Added support for **v860** and **v944**
* Added Bedrock data assets for **v924** and **v944**

### Core Translation System

* Introduced `PacketContext` for context-aware packet translation
* Introduced `PacketBatchTranslator` for batch-level packet processing
* Added `PacketSender` and `InterceptEncryptionContext` for low-level packet injection and interception
* Schema system now supports **direction-aware loading** (`inbound` / `outbound`)
* Added accessors:

  * `PacketTranslator::getSchemaRegistry()`
  * `SchemaTranslator::getSchemaRegistry()`

### Packet & Runtime Handlers

* Added:

  * `AnimatePacketHandler`
  * `InteractPacketHandler`
  * `InventoryTransactionPacketHandler`
* Added runtime mapping handlers:

  * `UpdateBlockRuntimeHandler`
  * `UpdateBlockSyncedRuntimeHandler`
  * `UpdateSubChunkBlocksRuntimeHandler`

### Tooling

* Added schema and data generation tools:

  * Block & item upgrade schema generators
  * Mojang patch generator
  * Protocol data generator improvements

### Debug

* Debugger can now be toggled via configuration

---

## Changed

* **Packet translation pipeline redesigned** with batch processing and context propagation
* **Schema system reworked** with registry-based and direction-aware architecture
* Block mapping system unified into `RuntimeBlockMapper`
* Chunk and runtime translation logic simplified and consolidated
* Listener pipeline updated:

  * Supports batch-only handlers
  * Skips already-translated packets
* Improved compatibility handling for:

  * `StartGamePacket`
  * `TextPacket`

---

## Fixed

* Crash on `AnimatePacket` (v860)
* Incorrect translation for:

  * `StartGamePacket` (v898, v860)
  * `TextPacket` (v860, v898)
* Debug logger `$ignore` handling

---

## Removed

* Legacy block translation components:

  * `BlockStateDictionary`
  * `BlockRuntimeIdTranslator`

---

## Internal

* Large-scale refactoring of translation, schema, and runtime systems
* Lazy loading implemented in `BedrockDataManager`
* Schema generator now supports structured overrides per field and packet
* Code style and cleanup across multiple handlers
