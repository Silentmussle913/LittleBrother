# v2.1.0-ALPHA

**Released: 29 May 2026**

For PocketMine-MP API 5.43.x (Minecraft: Bedrock Edition)

This alpha release introduces initial support for Bedrock protocol v1001 (Minecraft: Bedrock Edition v1.26.30), including a new `CreativeContentTranslationHandler`, updated block state metadata mappings, and an `IsEditorMode` flag for client data upgrades.

> [!WARNING]
> This is an experimental alpha release. Protocol translation behavior and internal mapping may change significantly as development continues.

---

## Added

- **Initial support for Bedrock protocol v1001** – Allows clients using protocol v1001 to connect.
- **`CreativeContentTranslationHandler`** – Adds runtime translation for `CreativeContentPacket`, enabling creative content synchronisation across protocol versions.
- **`block_state_meta_map.json`** – Provides additional data mapping for protocol v1001.
- **`IsEditorMode` option** – Added to `ClientDataUpgrader` to support editor mode functionality in protocol v1001.

---

## Changed

- Improved packet translation consistency for creative content workflows.
