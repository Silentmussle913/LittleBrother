# v1.0.1-ALPHA

**Released: 14 March 2026**

For PocketMine-MP API **5.41.x** (Minecraft: Bedrock Edition)

Patch release of **LittleBrother**, resolving critical bugs in the inbound packet translation pipeline and item runtime ID remapping that prevented players on older protocol versions from joining and interacting correctly.

> [!WARNING]
> This is an **experimental release** intended for development and testing.  
> Many packets are still incomplete and breaking changes may occur in future versions.

---

## Added

_No new features._

---

## Changed

- `TypeRegistryFactory` now caches `TypeRegistry` instances per protocol version instead of cloning on every packet, reducing per-packet overhead

---

## Fixed

- **Wrong packets being translated inbound** — translation is now guarded to only process packets registered in `ManualPacketRegistry`, preventing corruption of `LoginPacket`, `ItemStackRequestPacket`, and other packets that should not be touched
- **Item icons not visible in inventory** — `item_stack_wrapper` type registration was a passthrough with no ID remapping; now remaps `ItemStack::$id` using `ItemRuntimeIdMapper` for both inbound and outbound directions

---

## Removed

_Nothing removed._

---

## Internal

- `PacketTranslator::getManualRegistry()` getter added for use in `EventListener`
- `EventListener::onDataPacketDecode()` refactored: cancel-and-redispatch approach replaces ineffective reflection-based buffer patching

---

## Protocol Support

No changes to protocol compatibility matrix.
