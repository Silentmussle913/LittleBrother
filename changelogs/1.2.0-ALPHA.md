# v1.2.0-ALPHA

**Released: 26 March 2026**

For PocketMine-MP API 5.42.x (Minecraft: Bedrock Edition)

This release introduces major architectural changes to the schema compiler and protocol translation system, alongside initial support for newer and legacy Bedrock protocol versions.

> [!WARNING]
> This is an **alpha release**. Core systems such as schema compilation and protocol translation are still unstable and may produce inconsistent behavior across protocol versions.

---

## Added

* Introduced **TypeRegistry** for centralized and extensible type handling
* Added support for **Bedrock protocol v844**, including full data integration
* Uploaded **bedrock-data v844** (block states, canonical states, required item list)
* Added plugin instance injection into translator for better extensibility
* Extended schema support for:

  * entity attributes
  * block break/place sound and particle handling

---

## Changed

* Updated compatibility to support **PocketMine-MP API 5.42.0**
* Reworked **SchemaCompiler** to support multiple data type formats dynamically
* Updated generated schemas to align with latest protocol changes
* Reduced reliance on manual type handling
* Refactored multiple packet handlers:

  * `InventoryTransactionPacket`
  * `StartGamePacket`
  * `AnimatePacket`
* Improved runtime translators for:

  * `UpdateBlockPacket`
  * `UpdateSubChunkBlocksPacket`
* Improved schema generation pipeline (`generate-schema.php`)

---

## Fixed

* Fixed incorrect handling of **entity metadata variants**
* Fixed inconsistencies in **PacketContext handling**
* Fixed issues in entity attribute parsing and sound/particle emission
* Fixed minor issues in biome chunk generation parsing

---

## Removed

* Removed **DataPacketDecodeEvent**, simplifying the packet decoding flow
* Eliminated redundant and conflicting legacy decoding logic

---

## Internal

* Major refactor of **SchemaCompiler internals** (significant insertions and cleanup)
* Improved separation between schema definition and runtime execution
* Large reduction in code complexity (more deletions than insertions across core files)
* Updated internal schema build output (`build/schemas.php`)
* Improved maintainability of type system and registry handling
